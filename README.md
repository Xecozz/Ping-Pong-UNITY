# Ping Pong Game

This is a simple Ping Pong game developed using Unity.

## Project Structure

## Getting Started

### Prerequisites

- [Unity](https://unity.com/) (version X.X.X or later)

### Installation

1. Clone the repository:
   ```sh
   git clone https://github.com/yourusername/ping-pong-game.git
   ```
2. Open the project in Unity.

### Usage

- Use the arrow keys to control the paddles.
- The goal is to score by getting the ball past the opponent's paddle.

### Project Files

- **Assets/Ball.cs**: Script for the ball behavior.
- **Assets/GameManager.cs**: Script for managing the game state.
- **Assets/Goal.cs**: Script for goal detection.
- **Assets/Paddle.cs**: Script for paddle behavior.
- **Assets/player.prefab**: Prefab for the player paddle.
- **Assets/Scenes/**: Contains the game scenes.
- **Assets/TextMesh Pro/**: TextMesh Pro assets for UI text.
